# Skill Usage Review

Use only calls, results, errors, and outcomes visible in the conversation;
do not rerun work, modify files, or collect new telemetry. State material gaps
in the available history.

Give a concise assessment with concrete evidence and prioritized improvements.
Consider correctness, evidence sufficiency, safety, and economy independently;
less work is not an improvement when it loses necessary verification or safety.
Identify actual retries, repeated reads, repair work, and avoidable output when relevant.

Provide scores or quantitative efficiency estimates only when requested.
Use available matching-version metrics as supporting evidence, not quality scores;
character counts are not exact token counts. Explain estimates and their limits,
and do not combine different quality dimensions into one score.
